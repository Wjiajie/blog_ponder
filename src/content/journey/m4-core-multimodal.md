## 这个月要做什么

第 13 周：LoRA / QLoRA 微调——在一个开源小模型（Qwen2.5-7B / Llama-3-8B）上做 LoRA 微调，训练数据用教育领域问答。

第 14 周：语音 + LLM——用 MiniMax Speech API + M-Text-01 拼一个语音对话 demo（如 AI 英语口语陪练）。

第 15 周：视频生成 + LLM（我的图形学老本行）——用 Hailuo 视频生成 API 做「AI 生成教学情境视频」的 demo。

第 16 周：**教育项目 1：AI 学科 Agent 助教**——端到端 MVP：根据错题自动生成讲解、变式题、知识点讲解视频的 Agent Web 应用。

## 这个月要建立的能力

- 何时该微调、何时该 RAG、何时该换 Prompt 的决策树
- 多模态（语音 + 视频 + 文本）的端到端集成
- 第一个可写进简历的「教育行业 AI 项目」
