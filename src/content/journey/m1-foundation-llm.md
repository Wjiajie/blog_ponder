## 这个月要做什么

第 1 周：LLM 基础 + Prompt 工程，能用 Python 调通 OpenAI / Anthropic / MiniMax 三家以上 LLM API，写出结构化的 Prompt 模板。

第 2 周：Transformer 原理 + 主流模型能力边界对比（M2.5 / GPT-4o / Claude 3.7 / DeepSeek），输出一页纸的对比报告。

第 3 周：AI Coding 工具深度使用 + 系统设计思维——用 Cursor / Claude Code / MiniMax Code 从零搭一个 TODO API。重点**不是写代码**，而是写 PRD、review 生成的代码、定位 bug。

第 4 周：Docker 容器化 + 部署上云（阿里云/腾讯云）+ CI/CD（GitHub Actions）。

## 这个月要建立的能力

- 写高质量 Prompt（5 行 vs 50 行 PRD，AI 输出质量差 10 倍）
- 扫读 1000 行 AI 代码定位 3–5 个真实 bug
- 架构判断力：为客户场景选对技术栈并能解释为什么
- 部署能力：Docker + 云厂商 + CI/CD 跑通
