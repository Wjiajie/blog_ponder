# 🔥 热点信息速递 — 2026-07-19

今天最值得盯的，不是又冒出一个新模型，而是“部署层”终于越来越像一门正经行业了。OpenAI、Anthropic、Salesforce、Palantir 这几家都在把企业 AI 的最后一公里做成制度、产品和伙伴网络；另一边，Qwen3.8、ChatGPT Work、超长上下文 RL、搜索型 agent 和具身智能的工程化进展，也都在往“真能干活”那条线上挤。


## FDE 行业发展

这一周最明显的变化，不是又多了一个“企业要上 Agent”的口号，而是大厂把部署层、交付层、伙伴层都开始制度化了。FDE 不再只是 Palantir 早年的一种工作法，已经越来越像企业 AI 落地的标准工种。

1. **OpenAI 把“deployment company”写进企业主叙事**
   时间：2026-04-08
   OpenAI 在《The next phase of enterprise AI》里把话说得很直白：企业收入已经占到整体收入的 40% 以上，而且预计到 2026 年底会接近与消费端持平。更关键的是，他们不再把自己只定义成模型公司，而是明确说自己也是一家 deployment company，已经把和数百家大型企业一起落地 AI agent 的经验沉淀成可规模化的基础设施和交付方法。这说明 FDE 式能力已经从项目救火，升级成平台级能力。
   原文链接：https://openai.com/index/next-phase-of-enterprise-ai/

2. **OpenAI Partner Network 开始把 FDE 经验外溢给伙伴生态**
   时间：2026-06-14
   OpenAI 发布 Partner Network 时，专门提到一个试点中的 **Forward Deployed Experts** 计划。它不是泛泛的合作伙伴培训，而是要让合格的服务伙伴更贴近 OpenAI 自己的 Forward Deployed Engineering 团队，在复杂企业部署里共享 playbook、技术路径和转型模式。这个动作很关键，意味着 FDE 已经不是内部岗位扩张这么简单，而是在变成可复制、可授能、可渠道化的交付体系。
   原文链接：https://openai.com/index/introducing-openai-partner-network/

3. **Salesforce 把 FDE 当成 Agentforce 成败的关键岗位来建**
   时间：2026-03-27

## LLM 理论

1. **LongStraw 把超长上下文 RL 后训练拉到了 200 万 token 以上**
   时间：2026-07-19
   这篇工作想解决一个很现实的问题：推理阶段的上下文已经越来越长，但 RL 后训练仍然大多卡在 256K 左右。LongStraw 的做法是用更懂硬件约束的执行栈，把共享 prompt 无梯度评估，只保留后续必须的状态，再把响应分支逐个回放。它追求的不是论文里那种“漂亮设定”，而是固定 GPU 预算下到底还能把训练上下文撑多长。
   原文链接：https://huggingface.co/papers/2607.14952

2. **VideoChat3 继续把开源视频理解模型往“通用型”推进**
   时间：2026-07-19
   这项工作聚焦的是开源视频多模态模型的几个老毛病：动作理解不稳、长视频处理吃力、流式交互差。它想做的不是某个单点 benchmark 破纪录，而是把视频理解真正推向更通用、可落地的应用边界。
   原文链接：https://huggingface.co/papers/2607.14935

3. **SEED 把 agentic RL 的蒸馏路线继续往前拧**
   时间：2026-07-19
   论文关心的是长时程、多轮交互、要调用工具还得吃环境反馈的 agent 训练问题。它尝试用 self-evolving on-policy distillation 缓解 outcome-based RL 在这类任务上的稀疏反馈和训练不稳问题。放到今天的 agent 研究脉络里看，这更像是在补“怎么把代理训练得更像真干活的人”这条短板。
   原文链接：https://huggingface.co/papers/2607.14777
